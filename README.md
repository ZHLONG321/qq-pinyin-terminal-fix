# QQ 拼音候选框修复

修复 QQ 拼音在 Windows Terminal 中不显示候选框的问题。

下载源码后，按下面的步骤编译，再执行修复或恢复。

## 哪些电脑可以用

- 64 位 Windows 电脑，系统类型为 x64。
- 已安装 QQ 拼音。

在 QQ 拼音 6.6.6304.400 和 Windows Terminal 1.24.12741.0 的免安装版上测试过，候选框可以显示，翻页和选字正常。其他版本不保证效果。

工具会根据 QQ 拼音文件里的指令和类型信息，自动寻找候选框的控制位置，不按版本号或固定的文件校验值限制使用。如果新版改动太大、无法找到唯一的位置，工具会跳过修复，输入仍交给原来的 QQ 拼音处理。

## 第一次使用

先准备两个工具：

1. 安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)。本项目的脚本需要 Python 3.11 或更新的 64 位版本，uv 会负责准备运行环境。
2. 安装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)。它负责把源码编译成修复所需的文件。安装时勾选“使用 C++ 的桌面开发”，并选中 MSVC x64/x86 构建工具和 Windows 10 或 11 SDK。

下载或克隆本仓库到电脑。在资源管理器中打开项目文件夹，确认里面能看到 `build.py`。点击顶部地址栏，输入 `cmd` 后按回车，就会在这个文件夹打开命令提示符。

依次输入下面两条命令，每条输入后按回车：

```cmd
uv sync
uv run build.py
```

第一条命令准备 Python 环境，第二条命令编译源码。看到“构建完成”后，就可以执行下面的修复命令。

本项目没有额外的 Python 依赖包。

## 修复

```cmd
uv run fix.py
```

程序会自动找到 QQ 拼音，把原来的输入法文件留作备份，再放入修复文件。

运行成功后，关掉所有 Windows Terminal 窗口再打开，也可以重启电脑。重新输入拼音，看看候选框能否显示，能否翻页和选字。

## 恢复

```cmd
uv run restore.py
```

程序会把原来的输入法文件放回去。运行成功后，同样要关掉所有 Windows Terminal 窗口再打开。

项目文件夹里的 `tmp` 保存操作备份和手动修复记录，请留在本地。恢复不需要重新编译。

## 遇到提示怎么办

- 提示找不到 `uv`：确认已安装 uv，关闭命令提示符后重新打开。
- 提示找不到 C++ 编译工具或 Windows SDK：打开 Visual Studio Installer，补选“使用 C++ 的桌面开发”和前面列出的组件，再重新编译。
- 提示找不到编译好的文件：先运行 `uv run build.py`。
- 提示文件访问被拒绝：用管理员身份打开终端，进入项目文件夹，再执行刚才的命令。平时使用 Terminal 可以照常用普通权限打开。
- 提示原文件备份的名字已被占用：到提示的 QQ 拼音目录查看 `QQPinyin.ime` 和 `QQPinyinOriginal.dll`。程序无法分清这两个文件时会停止，避免覆盖原来的输入法文件。

想看当前是否使用修复文件，可以运行：

```cmd
uv run qq_proxy_setup.py status
```

## 为什么这样可以修复

QQ 拼音收到 Terminal 发来的“控制台模式”通知后，会屏蔽候选框。本工具让 QQ 拼音在 Terminal 里恢复显示候选框，其余输入功能仍由原来的 QQ 拼音完成。

想看源码如何实现、修改了哪些位置，以及如何手动排查，可以看[开发说明](docs/development.md)。
